# Masum Zahirul — Personal Website (Version 1)

- `index.html`: complete static website; images, CSS and JavaScript are embedded.
- `CNAME`: custom domain `www.masumzahirul.com` (connect it in GitHub Pages settings when ready).
- `.nojekyll`: disables Jekyll processing.

## GitHub Pages setup
1. Create a public repository on GitHub.
2. Upload the contents of this folder to the repository root. `index.html` must be at the root.
3. Open **Settings → Pages**. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. When ready to connect your domain, enter `www.masumzahirul.com` in **Settings → Pages → Custom domain**.
5. At your domain provider, configure the `www` CNAME record to point to your GitHub Pages hostname. Enable **Enforce HTTPS** when available.
